# data/sorties

Fichiers finaux générés par `notebooks/02_feature_engineering.ipynb`.

- `X_train_freq_scaled.csv` : variables d’entraînement finales.
- `X_test_freq_scaled.csv` : variables de test finales.
- `y_train.csv` : cible d’entraînement, réservée à l’évaluation.
- `y_test.csv` : cible de test, réservée à l’évaluation.

Le découpage train/test est effectué avant toute transformation apprise. Les autres
représentations sont comparées en mémoire dans le notebook 02 et ne sont pas conservées.
